# Odin Recipes
This is the first official website I've worked on.
It consists of a main index page which has links of 3 recipe pages that I built. The purpose of this project is to build my HTML basics. And I built it by doing the following things:
- Created an HTML boilerplate using !+Enter.
- Used various HTML elements, tags and attributes for headings, lists, etc.
- Also added some CSS in the style element nesting in head tag.
- Created links and added a few to give credit for the recipes.
- Organised files and directories in local machine as well as github.
The hardest part I faced till now has been updating github. I hope it gets easier as I keep moving forward.
